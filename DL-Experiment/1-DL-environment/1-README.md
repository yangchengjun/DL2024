## 1-实验目的
掌握深度学习相关环境的安装与配置，包括 Python 和常用的深度学习库（如 PyTorch）的安装。
熟悉基本的数据操作和张量（Tensor）的处理方法，为后续学习深度学习打下基础。
探索数据的不同维度及其在深度学习模型中的应用。
学习如何使用张量进行基本的数学运算和维度变换，掌握张量广播机制和切片等操作。
通过实验，进一步理解深度学习的底层操作及其与传统编程语言的数据操作的区别。
## 2-实验性质
性质：基础性实验
本实验属于深度学习课程的基础实验，目的是让学生熟悉深度学习开发环境的配置和基本数据操作。
性质：操作性实验
通过亲手配置环境和操作数据，帮助学生理解深度学习框架的基本概念和用法。
## 3-实验要求

### 安装要求：
按照视频教程完成 Python 环境的安装配置，包括安装 Anaconda、Jupyter Notebook、PyTorch 等深度学习所需的库。
环境配置需支持 Windows 或 Ubuntu 系统。
截图记录安装过程中的关键步骤，确保安装成功。
### 数据操作要求：
学习并掌握不同维度张量的创建和操作方法。
探索张量的基本数学运算，包括加减乘除、矩阵乘法等。
理解广播机制并进行相关操作。
通过挤压、解压、扩展、重复等方式，掌握张量的维度变换。
使用索引、切片操作获取张量中的部分数据。
### 探索要求：
学生在实验过程中需结合自己的理解进行自主探索，不仅仅局限于提供的例程操作。
在数据操作环节，鼓励学生创造不同的数据操作方案，避免与例程完全相同的操作。
